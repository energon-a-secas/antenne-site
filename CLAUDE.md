# CLAUDE.md: Antenne

Fleet launches, features, and updates as a news feed.

**Live:** antenne.neorgon.com · **Port:** 8873

## Run

```bash
make serve
```

Then open http://localhost:8873. It must be served over HTTP: the app is ES modules, and `file://` blocks them.

## Data

- `localStorage['dispatch-state']`
- `localStorage['neo-auth:dev-key']`
- `localStorage['neokeys-prefs']`
- Convex tables: `accessRequests`, `draftEvents`, `drafts`, `members`, `publishRuns`, `publishedIds`, `rateEvents`, `seenRequests`, `settings` (see `convex/schema.ts`)
- `data/`: 1 file(s)

## Conventions

- Zero build step. Plain ES modules loaded by `js/app.js`.
- Header and footer come from the shared kits. Do not add site-local `.neo-footer` or `.header-bar` CSS.
- The fleet guideline is ~500 lines per module; `js/neorgon-auth.js` is already past it. Split when touching it, do not grow it further.
